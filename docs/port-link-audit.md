# Port link audit

Checked against the GitHub API on the build date. Scope: every GitHub port link in the catalog (792 links, 644 repos).

Sandbox limits: Telegram, Discord, itch.io, 4PDA, mirrors and other non-GitHub links could not be reached from the audit environment, so they are not verified here.

## Results

| Result | Count |
|---|---|
| archived | 8 |
| check-match | 246 |
| dead-release | 3 |
| ok | 535 |

- ok: repo exists, not archived, release tag exists, title or description matches the game.
- check-match: repo exists, but its name and description do not mention the game. Most are real ports under another name (e.g. Ocarina of Time → Shipwright). Shared multi-engine packs (com.n0n3m4.diii4a, com.mobilerpgpack.phone) are kept because their README lists the games they run.
- archived: repo is archived. The link still works, but the port is no longer updated.
- dead-release: the release tag is gone. The download link now points to the repo releases page.
